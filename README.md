# QUICK!

Timed category game: take turns naming things in a category before the clock runs out. Repeats, wrong answers and timeouts lose.

- 2-player on one device or online
- Tournament mode (2-16 players, bracket, host screen + phones)

Static files only; online play uses PeerJS.
